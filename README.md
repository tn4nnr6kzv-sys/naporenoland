# Saint-Léger-en-Yvelines, cadastre napoléonien

Plan d'assemblage (cote 78¹) calé sur la carte actuelle.

**[Ouvrir la carte](https://VOTRE-NOM.github.io/saint-leger-cadastre/)**

- `index.html` : carte interactive (Leaflet), fichier autonome
- `data/` : repères en GeoJSON et plan géoréférencé pour QGIS

Pour ajouter des parcelles : glisser un GeoJSON (WGS84) sur la carte.
